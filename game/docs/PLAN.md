## 2. Модель комнаты (Metroid NES)
- Комната = дискретный экран: локальные координаты (0,0) слева-снизу, размер W×H (≤40×22 — влезает в кадр;
  камера clamp'ится к границам комнаты = NES-аутентичность, нет протечек соседней геометрии).
- Двери по краям: {side:E/W/N/S, at, to, gate?, lock?} — gate = способность/кор/босс-флаг;
  lock = «открывается только с той стороны» (shortcut-петля, разблокируется навсегда).
- Мир: комната имеет map-координату (mx,my); world-origin = (mx*44, -my*26); коллизии — только солиды
  активной комнаты (смена списка при переходе → O(n) маленький).
- Вертикаль: шахты = комнаты с N/S-дверями + лестницы + wall-jump chimneys + лифты (transport-зоны).
- Хазарды: acid/spikes (damage-tick), crusher (таймер), phase-платформы (on/off), conveyor/wind (push),
  pogo-pin (отскок пого, урон сбоку), kill-plane (респаун на последнем сейв-терминале).
- Предметы: ability, core, chest(eddies/maxhp), save-терминал, shop, crack-стена (секрет, ломается ударом,
  подсвечивается сканером Shift).

## 3. Прогрессия и гейты (без софтлоков)
start → **servo** (мини-босс НЕОН n7) → открывает МЕГАБАШНЯ (n7→N) и ПРОМЗОНА (n8→E)
→ **wall** (мини-баш-босс МЕГА m3) → chimneys МЕГИ и СЕТИ · **hack2** (мини-босс ПРОМ p6) → открывает СТОКИ (n6→S)
→ **phase** (босс СТОКИ st4) → открывает ПУСТОШЬ (p4→E) · **cores×3** (p6, st4, pu4) → открывает СЕТЬ (m4→E)
→ финал: ГЛИТЧ-МАТЬ (s5). BFS-тест проверяет порядок и достижимость всех 39 комнат и всех наград.

## 5. Критерии приёмки → чем проверяются
- Запуск без ошибок консоли → tests/smoke.mjs (pageerror=0, stage=play).
- Связный граф, достижимость, нет софтлоков → tests/bfs_reach.mjs (exit 0).
- Платформинг обязателен для прогресса → tests/phys_check.mjs (door-to-door решаемость на нужном тире способностей) + ручные сценарии playtest.
- Узнаваемый стиль локаций → biomes.js паспорта + скриншоты 6 биомов (playtest).
- Читаемые паттерны врагов → enemydefs telegraph-контракт + F5-лейблы + скриншоты.
- Расширяемость: новая комната/враг = запись в rooms.js/enemydefs.js без правки ядра → демо-тест: комната добавлена данными (TESTS.md).
