# Враги: архетипы, паттерны, окна уязвимости

Регистр: `src/enemydefs.js` (`ENEMY_TYPES`, `BOSSES`). Спавны — в данных комнат (`rooms.js: enemies:[{t,x,y,o}]`).
Телеграф-контракт для всех: перед уроном windup (мигание core magenta + рост eye) — реальное окно уклонения;
урон исполняется только если игрок ВСЁ ЕЩЁ в радиусе на момент окончания телеграфа (честность из v1 сохранена).
Контактный урон есть у всех, кроме помеченных `contact:false`. F5 — живые лейблы состояний.

## Best-practices проход (HK/Metroid), раунд 4
- **Видимая угроба до урона**: scan_turret получил ВИДИМЫЙ скан-луч (жёлтый → magenta при локе); jammer — кольцо-пульс
  с impactRing и звуком; все боссы — announce-имя при intro; ПРЕСС — маркер-колонна + полоса на полу.
- **Геометрическая честность патролей** (Metroid): patrol_bot и chaser_dog (вне aggro) разворачиваются на кромке платформы
  (groundAhead), а не сваливаются в ямы — паттерн читается и держит зону.
- **Физика врагов**: isFlyE теперь из def.fly (стаггер летающих = возврат к якорю, наземных = гравитация); логический y
  летающих больше не тонет на пол.
- **Fairness к игроку**: контактный хитбокс врагов ×0.85 от силуэта; knockback не закидывает в двери (knockT);
  step-up assist ≤0.35u — бег не спотыкается о низкие кромки полов.
- **Sec-двери**: авто-взлом при наличии ВОЕННЫЙ ВЗЛОМ (раньше оставались закрытыми до перезахода).
- **Punish-окна**: у каждого босса явное окно (stun/overheat/open) с визуальным маркером (вент/искры/покачивание).

## Взаимодействие с вертикалью и боем
- Пого (S+J) работает по всем врагам и пинам: hopper/mite в воздухе = батуты через шипы/кислоту.
- shield_guard и saw_rail учат обходу, а не танкованию; scan_turret и jammer учат приоритету целей.
- Боссы спроектированы вокруг платформ арены: волны по полу = прыжок, гейзеры = смена полки, таран = dash в сторону.
