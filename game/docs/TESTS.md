## Фиксы по фидбэку (раунд 11: «с base-тира не запрыгивается на цепи»)
1. **Corner-correction** (Celeste-grammar) в resolveX: касание бока СПЛОШНОГО блока в воздухе с ногами ≤0.55u от его
   верха = засасывание на площадку; дрейф в прыжке прощает ранний заход.
2. **Проектное решение по «жёсткому миру»**: сплошные = стены/полы/ямы/муверы/барьеры/sec-двери (support-геометрия),
   а полки цепей = **one-way** (HK-грамматика: запрыгивание снизу допустимо, посадка точная, без проваливания).
   Доказано тестами: полностью сплошные полки делают base-подъёмы невозможными (bonk головой в полку на два уровня
   выше, окна разбега вырождаются до 0.3u) — playability > буквальный «реализм».
3. phys_check: thin-цели разрешают overlap-прыжки (one-way), JUMP_DY 2.8; сохранены норматив люка, S-отверстия,
   ride/phase-муверы; lane/corridor/stand-room правила для thin сняты (one-way не блокирует проход под полкой).
4. **n5 «ВЕРТИКАЛЬ ДОЖДЯ» пересобрана** клоном проверенной цепи n3 (старая была бракованной на base: шаг 3.0 > 2.9);
   верхние полки всех цепей приведены к top 19.2 (норматив люка); n9 уже пересобрана в раунде 10.
5. Боты: держанный прыжок (variable jump: тап = хоп 1.95, держание = 2.9 — фича, не баг), умный jump-по-gap,
   inv-изоляция геометрических шагов от боёвки.
6. Тесты base-подъёмов `tests/climb_base.mjs` (n3, n5: все 8 ступеней + люк, без способностей) — PASS;
   `n9_climb` PASS; полный регресс после one-way реверта: playtest/transitions/portal_audit/bosses_visual/
   boss_press/fx_parallax/phys/bfs/audit — ALL PASS, 0 ошибок консоли.

## Фиксы по фидбэку (пост-v2.0)
1. **«Погибает при выходе вверх»**: doorSpawnPoint для S-стороны добавлял origin комнаты дважды → спавн за kill-plane.
   Исправлено: спавн на кромке пола у люка (мировой Y без двойного offset), сторона кромки выбирается по наличию
   опоры/отсутствию хазардов/конвейеров; для shaft-дверей (труба st2) — выброс вверх из люка.
2. **«Отбрасывает обратно наверх»**: верхние полки цепей попадали в старую N-зону люка (y0=h-1.0) → re-trigger.
   Исправлено: N-зона сжата до y0=h-0.35 + velocity-guard для всех дверей (N: vy>1, S: vy<-1, E/W: |vx|>0.5) —
   переход только при движении в дверь; стойка на кромке/падение сквозь люк не триггерят.
3. **«Подпол» под приподнятыми полами** (стоки/сеть): периметральный пол генерировался ниже авторского → карман-ловушка
   и неверный holeFloor. Периметральный пол удалён (полы — данные комнат), holeFloorOf считает толстые плиты до top 12.5.
4. Муверы больше не выталкивают игрока сбоку (только посадка/перенос) — уходил с кромки трубы st2 в кислоту.
5. Нокбэк от урона не закидывает в двери (knockT 0.35 c); i-frames 1.0 c на прибытие в комнату.
6. Пресс в p2 сдвинут с точки прибытия из люка (x 28→34).

## Известные ограничения и следующие шаги
1. **Камера комнатная (clamp)**, без скролла на больших комнатах — осознанно (NES-грамматика); комнаты > экрана не поддерживаются.
2. Враги не респаунятся внутри комнаты до выхода из неё; боссы мертвы навсегда (метроидвания-классика).
3. Энцкилопедия v1 отключена (меню-айтем ведёт на карту); discovery-данные menu.js не используются — вернуть при желании.
4. Мерж статики per-room (4 меша), но анимированные/интерактивные меши отдельные; на very-low-end можно домержить двери/декор.
5. eco-режим (software-GL) отключает parallax и bake'ит материалы — стиль беднее, но стабилен (наследие кейсов v1).
6. Сложность боссов не тюнилась плейтестом на людях — телеграфы есть, тайминги могут потребовать правки (константы в enemydefs).
7. Секреты: трещины ломаются ударом; подсказка — сканер (Shift). Брошенных «невидимых» секретов без подсказки нет (осознанно).
8. Следующие шаги: комната-хаб с лифтом-метро между биомами; 2-3 side-босса; враг-платформер (движущаяся платформа-противник);
   маппинг геймпада; speedrun-таймер; локализация HUD.
