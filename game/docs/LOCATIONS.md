# Локации (6 биомов, 38 комнат)

Каждый биом = паспорт в `src/biomes.js` (fog/background/hemi/key/rim, материалы платформ/стен/кромок,
parallax-рецепт 3 слоёв, звуковой муд, UI-акцент) + данные комнат в `src/rooms.js`.
Скриншоты: `docs/screens/`.

---
## 1. НЕОН-СИТИ (neon) — 9 комнат · старт
- **Роль в прогрессии**: обучает базе (бег/прыжок/пого/фокус), выдаёт **СЕРВО-ПРЫЖОК** (мини-босс),
  отсюда три выхода: МЕГАБАШНЯ (N, гейт servo), ПРОМЗОНА (E, гейт servo), СТОКИ (S, гейт hack2).
- **Визуал**: дождливый ночной город: мокрый асфальт (тёмно-синий глянец), розово-голубой неон кромок,
  голограммы-вывески (holo-спрайты), fog #050810 18–46, rim magenta; parallax: мега-башни + неон-окна + билборды.
- **Фишка**: ямы-люки в подвал (S-лаз в СЕКРЕТ-ПОДВАЛ с трещиной-секретом); пого-пины над шипами у ворот промзоны.
- **Комнаты**: улица-хаб (n1), коридор с ямами кислоты (n2), боевая площадь (n3), сейв+магазин (n4),
  вертикаль дождя (n5), коллектор с кислотой и hack2-люком (n6), арена мини-босса (n7), ворота с пинами (n8), секрет (n9).
- **Враги**: patrol_bot (геом.), sine_drone (геом.), chaser_dog (реакт.); мини-босс **ДОЖДЬ-ОХОТНИК** (dash-дуэль + телеграф-колонны дождя).
- **Звук/UI**: муд base (FM-бас), акцент #00F5FF.
- **Связи**: n8→E p1 (servo); n7→N m1 (servo); n6→S st1 (hack2); n1↕n9 (лаз).

## 2. ПРОМЗОНА «ЦЕХ 7» (prom) — 8 комнат
- **Роль**: первый «производственный» ярус: учит тайминги прессов и конвейеров; выдаёт **ВОЕННЫЙ ВЗЛОМ** + **КОР-1**.
- **Визуал**: ржавчина и пар: fog #140C06, key amber 1.25, кромки orange/gold; parallax: трубы, искры, кожухи;
  платформы — ржавые плиты с янтарной кромкой.
- **Фишка**: **конвейеры** (тянут ±3.2), **прессы-крашеры** по таймеру (телеграф-тень), шлаковые ямы с пого-пинами.
- **Комнаты**: цех-вход (p1), конвейерная с прессами (p2), литейный с sec-сейфом (p3), диспетчерская сейв (p4),
  крановый пролёт с муверами (p5), арена ПРЕСС-777 (p6), склады с трещиной (p7), шлаковая яма (p8).
- **Враги**: hopper (таймер-прыжки), saw_rail (рельса, неуязвим), shield_guard (реакт., щит спереди), gunner-welder (реакт.);
  мини-босс **ПРЕСС-777** (прицельные сламы + ударные волны, stun-окно после 3-го промаха).
- **Звук/UI**: муд stanciya (индустриальный секвенсор), акцент #FF8C1A.
- **Связи**: вход из n8 (servo); p4→E pu1 (phase); p6 даёт hack2+core1.

## 3. МЕГАБАШНЯ «АРКОЛОГИЯ» (mega) — 5 комнат
- **Роль**: вертикальный неф: учит цепочки прыжков и люки N/S; выдаёт **МАГНИТ-ЦЕП** (wall-jump).
- **Визуал**: стекло/сталь и реклама: fog #0A0818, rim violet, кромки violet/gold; parallax: рекламные полотна,
  золотые окна, стеклянные колонны; платформы — светлые стальные плиты.
- **Фишка**: **лифт** (транспорт m2→m3, оживает после СМОТРИТЕЛЯ — shortcut), wall-chimney слева в m2 (секрет с сундуком),
  люки-потолки с цепочками до 2.6.
- **Комнаты**: фойе (m1), лифтовая шахта (m2), арена СМОТРИТЕЛЯ (m3), техэтаж сейв (m4), неон-витраж секрет (m5).
- **Враги**: scan_turret (скан-луч, геом.-реакт.), orbit_drone (орбита, геом.), gunner (реакт.);
  мини-босс **СМОТРИТЕЛЬ БАШНИ** (слам с высоты → ударные волны по полу → stuck-окно).
- **Звук/UI**: муд kristall (стеклянные пэды), акцент #7A4CFF.
- **Связи**: вход из n7 (servo); m2→N m3 (hack2); m4→E s1 (cores3).

## 4. СТОКИ (stoki) — 5 комнат
- **Роль**: подземный сектор: токсичная вода и биомасса; выдаёт **ФАЗОВЫЙ РЫВОК** + **КОР-2**.
- **Визуал**: зелёный неон и туман #041008 (ближний fog 14–38), био-люминесцентные кромки; parallax: трубы стоков,
  светящиеся полосы слизи; платформы — биомасса.
- **Фишка**: **кислотные моря** (урон-тики, замедление), трубчатый спуск в гнездовье, гейзеры босса (телеграф-кольца).
- **Комнаты**: приёмный коллектор (st1), кислотный ручей с мувером (st2), насосная сейв (st3), гнездовье босса (st4), биомасса (st5).
- **Враги**: grid_mite (сеточные шаги, геом.), ambusher (засада-клоак, реакт.), summoner (призыв митов, реакт.);
  босс **МАТКА СТОКОВ** (гейзеры + прыжок-слэм + призыв).
- **Звук/UI**: муд stoki (булькающий saw), акцент #39FF14.
- **Связи**: вход из n6 (hack2); st4 даёт phase+core2.

## 5. ПУСТОШЬ «БЭДЛЕНДС» (pusto) — 5 комнат
- **Роль**: открытый ветер и разломы: проверка dash/прыжка; выдаёт **КОР-3**.
- **Визуал**: токсичный закат: fog #241A10 (дальний 60), key 1.5 тёплый, кромки amber/orange; parallax: солнечные панели,
  остовы машин, пыльные силуэты; платформы — песчаник.
- **Фишка**: **ветровые зоны** (сносят ±3.4), шипованные разломы, узкие уступы над пропастью.
- **Комнаты**: дюнный пост (pu1), ветровая аллея (pu2), солнечная ферма сейв (pu3), разлом босса (pu4), ангар бродяг секрет (pu5).
- **Враги**: hopper-sand, saw_rail-disk, gunner-scav, chaser_dog-rust; босс **ЧЕРВЬ «СИРОККО»**
  (буррование с песчаным трейлом-телеграфом → выход-укус → open-окно; <50% — песчаные волны).
- **Звук/UI**: муд venti (ветровой square), акцент #FFB040.
- **Связи**: вход из p4 (phase); pu4 даёт core3; pu3↕pu5 shortcut-замок.

## 6. КИБЕРПРОСТРАНСТВО «СЕТЬ» (set) — 6 комнат · финал
- **Роль**: нематериальный мир: ритм-платформы и глитч; финальная арена.
- **Визуал**: wireframe-неон: fog #0A0414, rim cyan, кромки magenta/cyan; parallax — светящиеся рейки-сетки (wireframe-материалы);
  платформы — светящиеся фиолетовые слэбы.
- **Фишка**: **фазовые платформы** (on/off 2.4 c, со сдвигом фаз), барьеры под ФАЗОВЫЙ РЫВОК, кэш-сейф-секрет.
- **Комнаты**: вейл-вход (s1), grid-холл с фазами (s2), ядро-антей со скан-демонами (s3), архитектор (s4), трон (s5), кэш-сейф (s6).
- **Враги**: orbit_drone-prog, jammer (глушит dash/hack на 3 c), scan_turret-daemon, grid_mite-sprite;
  мини-босс **АРХИТЕКТОР СЕТИ** (телепорты по узлам + wireframe-кресты); финал **ГЛИТЧ-МАТЬ** (3 фазы: орбы/таран-stun/веер/телепорт, адды).
- **Звук/UI**: муд set (глитч-арпеджио), акцент #FF2D78.
- **Связи**: вход из m4 (cores3); s5 — финальная арена, победа = ending.
