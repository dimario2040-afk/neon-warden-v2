# NEON WARDEN 2 — README

Cyberpunk-метроидвания (HTML5 + Three.js r165, single-file). Уровень-слой пересобран с линейной
сетки экранов v1 на **data-driven граф комнат в духе Metroid NES**: 38 комнат, 6 локаций,
ability-гейты, сейв-терминалы, карта с туманом открытия, shortcut-замки, секреты.

## Запуск
```bash
cd game
python3 -m http.server 8080      # любой статик-сервер
# открыть http://localhost:8080/dist/neon-warden_V2.html
```
Играбельно и без сервера (blob-loader), но с file:// Chrome может блокировать localStorage —
сейвы тогда живут только в памяти сессии. Рекомендуемый путь: сервер.

Пересборка из исходников:
```bash
node build.mjs        # src/* + shell/head.html → dist/neon-warden_V2.html
```

## Тесты
```bash
node tests/bfs_reach.mjs     # граф: связность, прогрессия способностей, софтлоки, карта
node tests/phys_check.mjs    # платформинг: двери/предметы/арены решаемы на своём тире способностей
node tools/audit_support.mjs # геометрия: ничего не висит в воздухе и не утоплено
# headless-прогоны (нужен playwright-core + chromium, см. work/test):
node playtest.mjs            # см. tests/PLAYTEST-HOWTO ниже
```

## Управление
| Клавиша | Действие |
|---|---|
| WASD / стрелки | движение; S в воздухе — fast-fall; S+Space на платформе — drop-through |
| SPACE | прыжок (coyote+jump-buffer); у лестницы — лазание |
| J | удар (гвоздь); **S+J** пого-отскок; **W+J** ап-сwing |
| K | dash (i-frames); с ФАЗОВЫМ РЫВКОМ — сквозь фиолетовые барьеры |
| F | ФОКУС: 33 RAM(SOUL) → 28 HP, прерывается ударом/уроном |
| L | quickhack (33 RAM): урон по цели в конусе |
| E | взаимодействие: сундук / терминал / магазин / лифт |
| SHIFT | сканер: подсвечивает трещины-секреты и сундуки |
| TAB | карта мира (туман открытия, иконки, гейты) |
| ESC | пауза · M звук · P качество/bloom · F9 сброс сохранения |
| F1/F2/F4/F5/F6 | debug: телепорт по комнатам / коллайдеры / граф / состояния врагов / физика |
| `__DBG` | консоль: `tp('p6') give('wall') killall() killboss() bfs() fps()` |

Способности: **СЕРВО-ПРЫЖОК** (double jump) → **МАГНИТ-ЦЕП** (wall-slide/jump) →
**ВОЕННЫЙ ВЗЛОМ** (sec-двери) → **ФАЗОВЫЙ РЫВОК** (барьеры) + 3 КОР-модуля → финал.

## Нормативы вертикальных конфигураций (зафиксированы, проверяются автотестом)
Для комнаты с потолочным люком (N-дверь) и верхней полкой цепи под ним (top = T, высота комнаты h):
- **Доставка в люк**: (h − 0.35) − T ≤ 2.6 — base-прыжок (2.9) должен пробивать зону люка (y0 = h − 0.35) со скоростью vy > 1.
- **Зазор над головой**: T ≤ h − 2.8 — стоя на полке, голова игрока (1.9u) имеет ≥ 0.9u до потолка: блоки потолка не срезают манёвр и сход с полки.
- Итого для h = 22: **T ∈ [19.05, 19.2]** (во всех N-комнатах выставлено 19.2).
- **Проём люка**: ±2.0u по X (HATCH_HALF в levelbuild) — выход вверх не требует пиксельного центрования.
- **Коллизионная грамматика**: support-геометрия (стены/полы/ямы/муверы/барьеры) — сплошные AABB; полки цепей —
  one-way с точной посадкой и drop-through по S+Space (HK-грамматика); corner-correction 0.55u на кромках сплошных
  блоков; step-up assist ≤0.35u; variable jump (тап 1.95 / держание 2.9).
- **ПРАВИЛО РОСТА (stand-room)**: над каждой площадкой стойки (ширина ≥1.4u) должен быть свободный от нависаний
  интервал ≥1.2u при клиренсе ≥2.1u (рост игрока 1.9u + запас); нависание = плита с низом в [T+0.3, T+2.1).
  Коридоры дверей E/W — ≥1.0u. Проверяется `tests/phys_check.mjs` на каждой комнате/полке/one-way.
- **LAUNCH-WINDOW**: если верхняя полка нависает над нижней (gap<0.45), на нижней обязано быть окно разбега ≥2.0u
  вне проекции верхней, step ≤2.75 (base) / ≤4.3 (servo) — иначе запрыгнуть мешает bonk/боковое выталкивание.
- **S-зона (дыра в полу)** = вся ширина проёма между плитами пола; спавн при подъёме — на кромку пола вне зоны (подбор стороны: опора → нет хазарда → нет конвейера к люку; иначе выброс вверх из люка).
- Переход срабатывает только при движении в дверь (velocity-guard): N vy>1, S vy<−1, E/W |vx|>0.5; нокбэк (knockT 0.35c) и стойка на кромке не триггерят.
Проверка: `node tests/phys_check.mjs` (норматив люка) + `node tests/portal_audit.mjs` (манёвр с полки: прыжок вверх и сход вниз).

## Как расширять (без правки ядра)
**Новая комната** = запись в `rooms.js` (+ двери в соседе):
```js
R({ id:"x1", biome:"prom", name:"ЦЕХ-Х", map:[6,2], enter:{x:2,y:0},
    solids:[[0,-2,40,2],[10,2.6,6,0.6]], doors:[{s:"S",at:20,to:"p2"},{s:"E",at:0,to:"x2",gate:"wall"}],
    enemies:[{t:"saw_rail",x:20,y:0,o:{x0:14,x1:30}}], items:[{t:"chest",id:"c_x1",kind:"eddies",x:12,y:3.2}] })
```
`node tests/bfs_reach.mjs && node tests/phys_check.mjs` проверят связность, гейты и проходимость.

**Новый враг** = запись в `ENEMY_TYPES` (enemydefs.js): `{ hp, dmg, fly, w, h, kind, ai(e,dt,ctx) }` +
спавн в комнате (`enemies:[{t:"my_enemy",x,y,o:{...}}]`). Телеграф-контракт: `ctx.telegraph(e,t,dmg,src)`.

**Новый биом** = паспорт в `biomes.js` (fog/light/mats/parallax/mood/uiAccent) + `biome:"<id>"` у комнат.

## Сохранения
localStorage `cybervania_v2`: способности, коры, боссы, посещённые комнаты, открытые замки,
сундуки, трещины, bench (последний терминал), eddies, статы, имя/путь. F9 — сброс.
Смерть → респавн на последнем терминале (полное HP, враги комнаты респаунятся, боссы мертвы навсегда).
